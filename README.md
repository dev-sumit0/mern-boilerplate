### MERN Stack Boilerplate

A clean and structured MERN stack template to kickstart your full-stack projects instantly.

## Quick Start Guide

1. Clone the repository
   git clone https://github.com/dev-sumitkumardudpuri/mern-boilerplate.git
   cd mern-boilerplate

2. Setup Backend
   cd backend
   npm install

3. Setup Frontend
   cd ../frontend
   npm install
   npm run dev
